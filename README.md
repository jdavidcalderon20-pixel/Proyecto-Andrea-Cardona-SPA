# Andrea Cardona SPA - Plataforma de Bienestar 🌿

Plataforma integral para la gestión de spas y centros de estética, diseñada para **Andrea Cardona SPA**. El sistema incluye un landing page interactivo para clientes y un panel administrativo completo para la gestión de servicios, productos, citas y fichas técnicas.

## ✨ Características Principales
- **Landing Page Dinámico**: Catálogo de servicios y productos que se actualiza en tiempo real.
- **Carrito de Compras Global**: Sistema persistente para productos y servicios orgánicos.
- **Panel Administrativo (Dashboard)**: Gestión de clientes, citas, stock y reportes financieros.
- **SEO Optimizado**: Enfoque local para Chinchiná, Caldas, y previsualización profesional en redes sociales.
- **Notificaciones**: Integración con EmailJS para confirmaciones de reservas y pagos.

## 🛠️ Stack Tecnológico
- **Frontend**: React 18 + Vite
- **Estilos**: Vanilla CSS + Materialize CSS
- **Backend**: Firebase (Auth, Firestore, Storage)
- **Email**: EmailJS
- **Imágenes**: Cloudinary

## 🚀 Instalación y Configuración

Sigue estos pasos para ejecutar el proyecto localmente:

1. **Clonar el repositorio**:
   ```bash
   git clone https://github.com/jdavidcalderon20-pixel/Proyecto-Andrea-Cardona-SPA.git
   cd Proyecto-Andrea-Cardona-SPA
   ```

2. **Instalar dependencias**:
   ```bash
   npm install
   ```

3. **Variables de Entorno**:
   Crea un archivo `.env` en la raíz del proyecto y añade tus credenciales de Firebase, EmailJS y Cloudinary (Ver guía técnica para nombres de variables).

4. **Ejecutar el servidor de desarrollo**:
   ```bash
   npm run dev
   ```
